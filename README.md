# FOX DROP

Food delivery platform for Syria, launching in Azaz and growing city by city.
It has four products: a customer app, a restaurant app, a captain (courier) app
and the owner's admin panel.

Status: specification. The V1 build specs and the approved technology stack are in
[`docs/`](docs/). No application code yet.
