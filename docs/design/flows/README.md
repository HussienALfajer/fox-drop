# Flows

One file per flow of an app, named `<app>-<flow>.md`. It is the flow's decision record through the steps in [`../README.md`](../README.md) (How design work runs): the analysis, the directions discussed, what was chosen and why, and where the screens live in Figma.

No flows yet.

Each file has the same sections: **Analysis** (entry points, steps, server routes and data, errors and limits, strings, states to design), **Directions** (each discussed idea with the owner's decision), **Choice** (the chosen direction, why, and the table of its `Draft/…` elements with their decision and layer), **Figma** (the Explorations section, the flow page and the latest audit result), **Reviews** (each approval with its date, who and the version-history checkpoint) and **Open points**.
