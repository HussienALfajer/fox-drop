# Flows

One file per flow of an app, named `<app>-<flow>.md`. It is the flow's decision record through the steps in [`../README.md`](../README.md) (How design work runs): the analysis, the directions discussed, what was chosen and why, and where the screens live in Figma.

| Flow                                    | App      | Step                              |
| --------------------------------------- | -------- | --------------------------------- |
| [Customer sign-in](customer-sign-in.md) | Customer | 1, analysis done; directions next |

Each file has the same sections: **Analysis** (entry points, steps, server routes and data, errors and limits, strings, states to design), **Directions** (each discussed idea with the owner's decision), **Choice** (the chosen direction and why), **Figma** (the Explorations section and the flow page) and **Open points**.
