# Domain reference (AP §8)

The shared domain rules of FOX DROP V1: order statuses, the captain track, timers, order money, captain custody and earnings, currencies, the restaurant account, customer trust, outcomes, tickets and platform accounts.

These sections are §8 of the [admin panel spec](../product/v1/admin-panel/README.md). All four specs and the technology stack cite them as "AP §8.n"; they live here because every product depends on them. A bare "§n" in these files means AP §n.
