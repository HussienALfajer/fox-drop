# TextArea

Long text: a box with a soft radius that shows three lines and grows to six, then scrolls.

## Counter

With `maxLength` the count («5/200») shows at the end of the line below, and typing stops at the limit; the count turns red when full.

## States

Rest, hover, focus (a 2 brand-orange outline), filled, invalid (red outline and the error below) and disabled, as in `TextField`.

## RTL and accessibility

The counter stays left to right so its digits read right. The label, the hint and the error come from the app's translation files and are the textarea's name and description.
