# Sidebar

The navigation of the panel and the owner portal, on the start side, with a collapsed form and a phone drawer.

## Behaviour

- Links with `aria-current="page"` on the current one; counts at the end, read with their words.
- Collapsed to 72: icons only, each name kept in a tooltip. A module without an icon yet shows a dot.
- `form: 'drawer'` below the tablet width: the same links in a drawer from the start side.
