# TopBar

The bar at the top of the panel and the portal: slots the app fills, icon actions read with their counts.

## Behaviour

- Slots: `start` (city, platform status, dispatch mode), the middle (search), `actions` (bell, approvals), `end` (user menu).
- On a phone, `menu` opens the sidebar drawer and `title` names the page. Sticky, with the banners under it.
