# BlockingHeads

The heads of the blocking screens: `BlockingHeads.VersionTicket` for the forced update and `BlockingHeads.ShopSign` for maintenance.

## Behaviour

- VersionTicket: a ticket with the installed version struck above a perforation and the required version below, beside the brand mark.
- ShopSign: an orange board hung by two strings from a nail, with the title, the subtitle and, when the panel gave one, `returnTime`.

## RTL and accessibility

Each head is one image read once by its `label`; its parts are hidden from screen readers. Versions show left to right; times and numbers in Western digits.
