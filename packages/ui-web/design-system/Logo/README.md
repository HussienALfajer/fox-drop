# Logo

A restaurant's logo in a rounded square, or the first letter of its name on a tint when it has none.

## Behaviour

- `src` shows the app's image, cropped to the square.
- Without it, the name's first letter (a Latin one in capitals) on the orange tint: never a drop, never a fake image (brand expression §5).

## RTL and accessibility

Decoration: the restaurant's name always sits beside it, so the logo is hidden from screen readers and its image has an empty alternative text.
