# EmptyState

An empty, error or offline state: an icon in the logo's drop, a title, a line, one action.

## Behaviour

- The drop frames a large icon; in the apps the fox scenes take its place once drawn and approved.
- At most one `action` («أعد المحاولة», «مسح الفلاتر»). `tone="error"` writes the title in red and makes the action primary.

## RTL and accessibility

The title is a heading; the drop is decoration and hidden from screen readers.
