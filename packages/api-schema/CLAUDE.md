# packages/api-schema

The API contract and the TypeScript client for the web apps (architecture §5.3, §19.1; E6).

## Contents

- `openapi.json`: the OpenAPI 3.1 document, generated from the server's controllers (`apps/server/src/http/openapi.ts`).
- `src/schema.ts`: its types, generated by `openapi-typescript`.
- `src/index.ts`: `createApiClient`, an `openapi-fetch` client typed by `src/schema.ts`, and the `paths` and `components` types. Written by hand.

## Rules

- `openapi.json` and `src/schema.ts` are never edited by hand. Change the server's routes and Zod schemas, then run `pnpm generate:api` from the repository root and commit what changed.
- `pnpm verify` regenerates them and fails when the committed files differ, so a stale contract never reaches `main`.
- A model reaches the client under its server name: a response DTO `StatusDto` declared with `@ZodResponse` is `components['schemas']['StatusDto_Output']`.
- A web app calls the server only through `createApiClient`, never with a hand-written `fetch` (E6).
